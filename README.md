## 🧠 Key Concepts

### 1. Traditional Programming vs. Machine Learning

Traditional programming relies on explicitly defined rules written by developers. Machine learning, on the other hand, uses data and learning algorithms to identify patterns and adjust model parameters.

Understanding this distinction helps explain why machine learning is particularly useful for tasks in which manually defining every rule is difficult.

### 2. Understanding Data

Data is the foundation of every machine learning system. In a supervised learning problem, a dataset typically contains input features and corresponding target values.

For example, in a house-price prediction task, the area, number of rooms, and building age can serve as input features, while the house price is the target.

### 3. Models and Predictions

A machine learning model can be viewed as a function that transforms input data into an output.

A simple linear model is represented by:

\[
\hat{y} = wx + b
\]

This equation introduces the relationship between input values, model parameters, and predictions. Although simple, it provides an intuitive starting point for understanding more advanced learning algorithms.

### 4. Understanding the Learning Process

A model is not necessarily trained simply because it produces a prediction. Training requires a learning procedure that uses data and an objective to adjust model parameters.

This lesson introduces the distinction between applying a predefined mathematical function and learning parameters from data.
